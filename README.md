# Vidya Enterprise Suite

We are starting development of Vidya Enterprise, a real B2B wholesale commerce and distribution management platform.

I want to build this application incrementally.

First, understand the business requirements and establish the application foundation.

TECHNOLOGY:

React/TypeScript application supported by Lovable

Tailwind CSS

shadcn/ui

Supabase PostgreSQL

Supabase authentication initially, unless a better supported configuration is available

APPLICATION INTERFACES:

Admin dashboard

Customer commerce portal

Salesperson dashboard

Delivery personnel interface

FIRST TASK:

Build the application shell with:

Premium professional enterprise design.

Responsive sidebar navigation.

Login and registration screens.

Role-aware dashboard layouts.

Admin dashboard.

Customer dashboard.

Salesperson dashboard.

Delivery dashboard.

Product catalogue interface.

Order management interface.

Customer management interface.

Pricing management interface.

Business modules should be clearly separated.

IMPORTANT:

This is an actual business application, not a static UI demo.

Use realistic sample data only for initial previews.

Do not pretend sample data is connected to a live database.

Use reusable components.

Do not build all backend modules yet.

Explain the application architecture before proceeding.

Preserve the existing project when making future changes.

Start by creating the application shell and design system.

This project was built with [Lovable](https://lovable.dev).
